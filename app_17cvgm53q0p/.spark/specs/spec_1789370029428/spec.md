# 需求分析
## 用户故事
1. 在客户管理页「销售进度」标签页查看重新设计后的销售漏斗
  - 1.1 漏斗自「线索」到「谈判中」使用同色系由浅到深渐变，「已成交」层为绿色，各层颜色区分明显
  - 1.2 各层宽度按客户数量比例映射、逐层收窄，左右对称居中，不出现中间宽上下窄的异常形状
  - 1.3 阶段名称显示在漏斗层左侧，客户数量以大号字体在层内居中显示，文字与背景对比清晰
  - 1.4 鼠标悬停某层时该层高亮，并提示该层客户数量与较上一阶段的转化率
  - 1.5 漏斗整体居中、高度适中，底部图例清晰美观，空数据/加载/失败状态正常展示
## 页面列表
### 客户管理页（销售进度标签）
1. 销售漏斗卡片以新渐变色系展示线索到已成交各阶段客户分布
2. 阶段名称置于层左侧、数量大号居中层内，底部横排色块图例
3. 悬停漏斗层高亮该层并提示客户数量与较上一阶段转化率
4. 卡片头部保留客户总数与成交率，空态/加载/重试沿用现有展示
## 非功能需求
- 视觉：线索→谈判中蓝色同色系由浅到深渐变、已成交成功绿；层内文字与背景对比度 ≥ 4.5:1；整体简洁专业、参考现代 CRM 风格
- 形状：各层为居中等腰梯形、左右对称；宽度按数量比例映射且逐层不增宽（后阶段数量超过前阶段时该层宽度封顶为前层宽度）
- 布局：漏斗水平居中，图表高度适中（约 320~360px），底部图例水平居中排布
- 适老化：沿用全局适老化规范，图表文字不小于现有正文层级
