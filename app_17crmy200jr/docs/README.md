## 项目简介

行政资产与支出管理系统是一套面向企业行政与资产管理人员的全流程管理平台，覆盖支出管理、固定资产管理、资产盘点、预算管理、审批流转、数据看板与飞书多维表格双向同步等核心业务场景。

### 技术栈

| 层级 | 技术 |
|------|------|
| 前端 | React 19 + TypeScript + Vite + Tailwind CSS |
| 后端 | NestJS 10 + TypeScript + PostgreSQL + Drizzle ORM |
| 数据同步 | 飞书多维表格双向同步 |
| 权限模型 | RBAC 三级权限（菜单/数据/操作） |

### 核心功能模块

- **综合数据看板** — 支出总览、趋势分析、类目/主体/楼层/部门分布、资产统计、预算执行
- **行政支出管理** — 支出记录 CRUD、审批流转、多维度筛选、批量操作
- **固定资产管理** — 资产全生命周期（采购→入库→领用→归还→维修→报废）、库存阈值预警
- **资产盘点** — 盘点任务创建、逐项确认、差异处理、库存调整、盘点报告导出
- **资产盘点看板** — 归属人矩阵热力图、盘点时间线、库存看板、异常列表
- **预算管理** — 预算编制、执行监控、调整记录、超预算预警
- **类目管理** — 一级/二级类目 CRUD、联动选项
- **数据统计与报表** — 支出分析、资产分析、盘点分析、Excel 导出
- **系统设置** — 飞书同步配置、审批流程配置、角色权限管理、操作日志
