## 目标与成功标准

对预算管理页面（`/budget`）进行浏览器验收测试，验证页面渲染正常、核心功能可用。

## 测试范围

- 页面加载：4 张统计卡片渲染、筛选栏就位、表格数据展示
- 新增预算：打开表单弹窗 → 填写 → 提交 → 表格出现新记录
- 编辑预算：点击编辑 → 弹窗回填数据 → 修改 → 提交 → 表格更新
- 删除预算：点击删除 → 确认弹窗 → 取消 → 记录未删除
- 批量设置：打开批量设置弹窗 → 验证表单字段

## 测试模式

`lite` — 基础视觉验证（截图检查页面布局、统计卡片、表格、弹窗是否正常渲染）

## 具体步骤

1. 创建测试计划文件 `.spark/e2e-test/lite/budget-acceptance.json`
2. 派发 E2E agent（`mode: "lite"`）执行验收，覆盖 5 个 Case：
   - Case 1: 页面加载 — 标题"预算管理"、统计卡片、筛选栏、表格均渲染
   - Case 2: 新增预算弹窗 — 点击"新增预算"打开弹窗，表单字段完整
   - Case 3: 编辑预算弹窗 — 点击编辑按钮，弹窗回填数据
   - Case 4: 删除确认弹窗 — 点击删除，确认弹窗出现，取消后记录未删除
   - Case 5: 批量设置弹窗 — 点击"批量设置"，弹窗表单字段完整

## 验收标准

- 页面无白屏、无明显布局错乱
- 统计卡片数字和进度条正常渲染
- 表格至少有 1 行数据
- 新增/编辑/批量设置弹窗能正常打开并包含表单字段
- 删除确认弹窗能正常打开和关闭
