# UI 设计指南

> **设计类型**: App 设计（应用架构设计）
> **确认检查**: 本指南适用于可交互的应用/网站/工具。

> ℹ️ Section 1 为设计意图与决策上下文。Code agent 实现时以 Section 2 及之后的具体参数为准。

## 1. Design Archetype (设计原型)

### 1.1 内容理解

- **目标用户**: 餐饮培训机构校长、招生老师、授课老师；高频办公场景，需快速处理数据与待办
- **核心目的**: 高效管理教务运营、辅助招生转化、沉淀教学知识资产
- **情绪基调**: 专业务实 / 清晰有序；避免花哨装饰与信息过载

### 1.2 设计方向

- **Design Style**: Soft Blocks 柔色块 — 教育行业需亲和力，数据密集场景用柔和层次区分信息区块
- **Application Type**: Admin/SaaS — 决定左侧导航 + 内容区多模块布局策略
- **Aesthetic Direction**: 暖调专业感，以琥珀橙为主色传递餐饮培训的温度与活力，搭配中性灰底保障长时间阅读舒适

## 2. Color System (色彩系统)

**色彩关系**: 琥珀橙主色 + 暖灰背景 + 深棕文字，从主色 HSL 衍生低饱和底色与边框
**配色设计理由**: 餐饮培训需区别于冷调 SaaS，暖色建立亲和信任；数据密集场景主色克制仅用于关键行动
**主色推导**: 琥珀橙呼应餐饮烟火气与招生转化能量，用于 AI 创作、新增、审核通过等核心操作
**使用比例**: 60% 暖灰中性底 / 30% 卡片白 / 10% 琥珀橙主色；主色收敛至按钮、状态标签、图表强调

### 2.1 主题颜色

| Token                | HSL 值           | 说明                           |
| -------------------- | ---------------- | ------------------------------ |
| `background`         | hsl(40 20% 97%)  | 暖灰页面底色，降低视觉疲劳     |
| `card`               | hsl(40 15% 99%)  | 卡片容器，微暖白               |
| `foreground`         | hsl(30 10% 15%)  | 深棕主文字，比纯黑更温润       |
| `muted-foreground`   | hsl(30 8% 50%)   | 次要说明文字                   |
| `primary`            | hsl(28 90% 55%)  | 琥珀橙主交互色                 |
| `primary-foreground` | hsl(0 0% 100%)   | 主按钮文字                     |
| `accent`             | hsl(28 60% 95%)  | Ghost/hover/focus 反馈背景     |
| `accent-foreground`  | hsl(28 80% 35%)  | accent 上的文字/图标           |
| `border`             | hsl(30 12% 88%)  | 分割线与卡片边框               |

### 2.2 导航区配色

- **基调关系**: 复用主配色系统，侧边栏背景取 `hsl(30 12% 96%)` 略深于内容区以区分层级
- **关键状态**: 激活项使用 `bg-accent` + `text-primary`；hover 态透明度渐变；对比度 ≥ 4.5:1
- **边界与背景**: 非透明暖灰底；右侧 1px `border` 分隔内容区

### 2.3 语义颜色

| 用途      | HSL 值          | 衍生逻辑                    |
| --------- | --------------- | --------------------------- |
| 成功/满员 | hsl(140 60% 45%) | 绿色系，边框中饱和、背景高明度 |
| 警告/临满 | hsl(38 85% 55%)  | 琥珀黄，与主色同色系但明度更高 |
| 错误/欠费 | hsl(5 75% 55%)   | 红橙系，醒目但不刺眼        |
| 待审核    | hsl(220 70% 58%) | 蓝紫系，区别于运营主色      |

## 3. Typography (字体排版)

- **Heading**: "Noto Sans SC", "PingFang SC", system-ui, sans-serif
- **Body**: "Inter", "Noto Sans SC", system-ui, sans-serif
- **字体策略**: 中文优先可读性，数字与英文用 Inter 保障对齐；标题 font-bold，正文 font-normal

## 4. Layout Strategy (布局策略)

- **导航意图**: 全局左侧边栏导航（已声明），按角色动态渲染菜单项；至多一套导航
- **页面架构**: 左导航 + 右内容区单栏流式布局，内容区 `max-w-[1400px]` 居中约束
- **响应式**: 移动端侧边栏折叠为底部 Tab Bar；桌面端保持左侧持久导航

## 5. Visual Language (视觉语言)

- **形态参数**: 圆角 `rounded-lg (0.5rem)` · 阴影 `shadow-sm` · 间距基调 `standard (gap-4/p-6)`
- **识别签名**: KPI 卡片左侧 4px 主色竖条标识；状态标签胶囊形带色底；表格行 hover 暖灰渐显
- **装饰策略**: 无多余装饰，仅通过色块层级与留白建立节奏
- **动效原则**: 交互反馈 150ms ease-out；页面切换 200ms fade-in
- **可及性**: 对比度 ≥ 4.5:1；复杂背景加遮罩；Focus ring 使用 `ring-2 ring-primary/50`

## 6. Component Principles (组件原则)

- **状态完整性**: Button/Input/Card 覆盖 Default/Hover/Focus/Disabled；表单 Error 态红色边框 + 下方提示文案
- **层级清晰**: Primary 按钮填充主色；Secondary/Outline 用 border + text-primary；Ghost 仅 hover 显背景
- **一致性**: 所有卡片统一 `rounded-lg shadow-sm p-6`；表格斑马纹用 `even:bg-muted/30`

## 7. Image Direction (图片与视觉资产)

- **Image Role**: 课程详情页产品缩略图、工作台空状态插画
- **Image Art Direction**: 暖调食物摄影风格，自然光侧照，木质/陶瓷质感背景，构图简洁主体居中
- **Image Prompt Keywords**: 中式餐食特写、自然侧光、木桌纹理、浅景深、暖色调、干净构图、食欲感、专业美食摄影
- **Image Avoidance**: 避免过度滤镜、摆拍僵硬、通用商务人物、抽象科技渐变、低分辨率素材

## 8. 应避免 (Anti-patterns)

- ❌ 使用冷蓝/紫色系主色 — 与餐饮培训温暖调性冲突
- ❌ 工作台堆砌超过 4 张 KPI 卡片 — 信息过载违背一屏掌握原则
- ❌ 配方/工艺流程区域添加装饰性插图 — 教学资料页需极致专注与可读性
