## 1. 目标与成功标准
- 解决当前页面显示「暂无访问权限」的问题，恢复正常功能访问
- 左侧菜单完整显示当前角色有权限的菜单项
- 不影响其他已正常用户的权限判断

## 2. 关键实现文件
- `client/src/app.tsx` — 路由鉴权与 `AuthProvider` 配置（已接入 `/api/auth/my-roles`）
- `server/modules/auth/auth.controller.ts` — 自建角色拉取接口
- `client/src/components/ProtectedRoute.tsx` — 路由级角色校验
- `shared/roles.ts` — 角色定义与页面角色映射
- `client/src/components/Layout.tsx` — 左侧菜单渲染与权限过滤

## 3. 实现方案

### 3.1 问题定位步骤
1. 确认当前预览 URL 路径（从截图看当前是 `/unauthorized`，之前被重定向到的页面未知）
2. 用浏览器控制台检查 `/api/auth/my-roles` 接口是否正常返回，`data.roleList` 包含哪些角色
3. 检查当前用户命中的角色与目标页面 `requiredRoles` 是否有交集
4. 检查左侧菜单的渲染逻辑是否也依赖同一套权限系统

### 3.2 修复方向（按可能性排序）
- **方向 A：首页重定向逻辑问题** — 登录后首页路由（`/`）指向工作台，但工作台可能要求 `principal` 角色，普通角色用户进入后被重定向到 `/unauthorized`。修复：`HomeRedirect` 根据用户角色重定向到第一个有权限的页面（如招生老师 → 学员管理，授课老师 → 课程排期，学员 → 课程列表）
- **方向 B：菜单渲染未走权限判断** — 左侧菜单直接硬编码或过滤逻辑有误，导致显示了无权限的菜单，点进去跳 403。修复：菜单项配置 `requiredRoles`，用 `useAuth` 过滤
- **方向 C：接口返回角色为空** — `AuthProvider` 拉取失败或缓存异常，`roleList` 为空导致所有页面拒。修复：增加接口失败降级（读 `req.userContext.roles` 兜底）、加错误日志
- **方向 D：角色映射表缺失** — 某个页面的 `PAGE_ROLE_MAP` 未配置，默认无权限。修复：补齐映射，无配置时默认放行或按角色策略处理

## 4. 具体步骤

### 步骤 1：定位触发页面
- 读取 `client/src/components/HomeRedirect.tsx` 与 `client/src/app.tsx` 中的 index 路由逻辑
- 读取 `shared/roles.ts` 的 `PAGE_ROLE_MAP` 确认各路径的角色配置
- 读取 `client/src/components/Layout.tsx` 确认菜单项是否有权限过滤

### 步骤 2：修复首页重定向
- `HomeRedirect` 组件：引入 `useAuth` 获取当前角色列表
- 按角色优先级从 `PAGE_ROLE_MAP` 找到第一个匹配路径，`navigate(path, { replace: true })`
- 角色优先级：`principal` → `/`（工作台），`recruitment_teacher` → `/students`，`teaching_teacher` → `/schedules`，`student` → `/courses`
- 无任何匹配时仍跳 `/unauthorized`

### 步骤 3：修复菜单权限过滤
- 若 Layout 菜单未做权限过滤：给每个菜单项加 `requiredRoles` 字段，用 `useAuth().can` 或直接比对 `roleList` 过滤
- 确保菜单过滤与 `ProtectedRoute` 使用同一套角色数据（都是 `AuthProvider` 提供）

### 步骤 4：补充兜底与日志
- `auth.controller.ts` 接口异常时返回空角色但加 logger.error 记录
- 前端 `AuthProvider` 拉取失败时 console.error（用 logger），不静默失败

## 5. 影响范围与风险
- 影响所有登录用户的首页跳转和菜单展示
- 风险：角色优先级配置错误可能导致某些角色用户跳错页面 → 通过逐个角色验证规避
- 不影响后端数据接口的鉴权（后端 `@CanRole` 独立生效）

## 6. 验收标准
- 校长账号登录 → 看到完整菜单 + 工作台正常显示
- 招生老师账号登录 → 自动跳学员管理，菜单仅显示学员/内容中心/智能咨询等有权限项
- 授课老师账号登录 → 自动跳课程排期，菜单显示课程排期/考勤等
- 学员账号登录 → 自动跳课程列表，菜单极简
- `/api/auth/my-roles` 返回 2xx 且 `data.roleList` 非空
- 无权限页面仍正确显示「暂无访问权限」并可返回可访问页面
