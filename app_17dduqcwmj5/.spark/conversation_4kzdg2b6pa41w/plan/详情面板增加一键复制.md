## 目标与成功标准

- 内容详情面板的「内容正文」区域右上角增加「一键复制」按钮
- 点击后将全文复制到剪贴板，成功后 toast 提示「已复制到剪贴板」
- 复制失败（如浏览器权限限制）时 toast 提示错误信息，不阻塞面板

## 关键实现文件

- `client/src/pages/content-center/ContentDetailSheet.tsx` — 正文区右上角加复制按钮 + 复制逻辑

## 实现方案

**复制按钮**：放在「内容正文」标题行右侧（与标题同一行，flex justify-between），使用 `Button variant="ghost" size="sm"`，图标用 `lucide-react` 的 `Copy`。点击后调用 `navigator.clipboard.writeText(detail.body)`，成功 `toast.success('已复制到剪贴板')`，失败 `toast.error(extractErrorMessage(err, '复制失败'))`。

**复用已有工具**：extractErrorMessage 已在同文件引入；sonner toast 已在项目中使用；Copy 图标来自 lucide-react（项目已安装，与现有 List/CalendarDays 等同库）。

**边界情况**：
- 加载中或 detail 为空时不显示按钮（与正文区同条件渲染）
- 空 body 也可点击复制（复制空串无副作用）
- 不支持 secure context 的环境（如 http 预览）clipboard 可能不可用，走 catch 分支提示

## 具体步骤

1. `ContentDetailSheet.tsx` 引入 `Copy` from 'lucide-react'
2. 正文区标题行改为 flex justify-between items-center，右侧放复制按钮
3. 实现 `handleCopy` 函数，async 调 clipboard API，成功/失败分别 toast
4. 自测：打开详情面点复制 → 粘贴验证文本一致 → 检查 toast 提示

## 影响范围与风险

- 仅改动详情面板一个文件，不影响列表/日历/其他模块
- clipboard API 需要 https 或 localhost，当前本地 dev 环境可用；若预览环境为 http 可能不可用，已做错误兜底

## 验收标准

- 详情面板正文区右上角可见「复制」图标按钮
- 点击后 toast 显示「已复制到剪贴板」，剪贴板内容与正文完全一致
- 按钮 loading/成功/失败状态有视觉反馈（可选：点击后图标短暂变 Check 再恢复）
