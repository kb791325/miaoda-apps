## 目标与成功标准

- 内容管理列表每行可点「查看详情」，右侧滑出面板展示该条内容的完整信息（正文、状态、类型、关联课程、计划发布日期、发布平台、效果数据、驳回原因、创建时间）
- 日历视图的每日弹窗内每条内容也可点「查看详情」，打开同一面板
- 成功标准：AI 创作生成的内容，在列表/日历两个视图均能查看到完整正文与相关信息

## 实现方案

**后端详情接口**：`getContentDetail` 按 id 查 `marketingContent`，leftJoin 课程表取 courseName（与 listContents 相同的映射），返回 `MarketingContentDetail`；不存在抛 `NotFoundException`。

**详情面板 ContentDetailSheet**：基于 `components/ui/sheet`（side="right"，sm:max-w-lg）。props：`open`、`contentId: string | null`、`onClose`。打开且 contentId 变化时调 `fetchMarketingContentDetail` 拉取；loading 用 Skeleton，失败 toast 错误。布局分区：
- 头部：标题 + StatusBadge
- 信息区（两列网格）：内容类型、关联课程、计划发布日期、发布平台、创建时间、点赞数/转化数（未录入显示「-」）
- 驳回原因：仅 `status === 'rejected'` 时显示，红色提示块
- 正文区：`whitespace-pre-wrap break-words` 可滚动区块，占面板剩余高度

**入口挂载**：
- 列表：操作列所有状态均渲染「查看详情」（ghost、size sm，置于按钮组最前），点击回调 `onViewDetail(record.id)`
- 日历：每日弹窗卡片右侧加「查看」小按钮，点击回调 `onViewDetail(content.id)`（阻止冒泡无需，卡片非整体可点）
- ContentManageTab 持有 `detailId` 状态，`ContentDetailSheet open={detailId !== null} contentId={detailId}`

## 具体步骤

1. `shared/content.ts` 加 `MarketingContentDetail` 别名类型
2. `content.service.ts` 加 `getContentDetail`；`content.controller.ts` 加 `GET ':id'` 路由（在 `/calendar` 之后）
3. `content.api.ts` 加 `fetchMarketingContentDetail`
4. 新建 `ContentDetailSheet.tsx`
5. `ContentTable.tsx` 加按钮与 prop；`PublishCalendar.tsx` 加按钮与 prop；`ContentManageTab.tsx` 挂状态与面板
6. 自测：api_request 验证 `GET /api/marketing-contents/:id`（真实 id 返回 200 含 body；随机 uuid 返回 404）；读运行时日志确认无错后提交

## 影响范围与风险
