- 课程类别从硬编码常量改为可配置数据：管理员能在课程列表页管理类别（新增、删除），表单弹窗与列表筛选的类别下拉实时反映最新类别列表

## 实现方案

### 数据层
- 按 `lark-apps-db` skill 流程新建表 `course_category`：id uuid 主键、name varchar(255) NOT NULL UNIQUE、created_at；执行 `INSERT INTO course_category (name) SELECT DISTINCT course_category FROM course_general_table WHERE course_category IS NOT NULL AND course_category <> ''` 回填存量类别
- DDL 完成后重新读取生成的 `schema.ts`，再编写业务代码

### 服务端
- `shared/course.ts`：`CourseCategory { id: string; name: string }`、`CreateCategoryRequest { name: string }`、`CategoryListResponse { items: CourseCategory[] }`；删除 `COURSE_CATEGORY_OPTIONS`
- Service：`listCategories()`（按 name 排序）、`createCategory(name)`（trim、非空、≤255 字符；捕获 23505 unique violation 转 `ConflictException('该类别已存在')`，用 cause-aware 错误码提取）、`deleteCategory(id)`（先 count `course_general_table.courseCategory = name`，>0 抛 `ConflictException('该类别下仍有课程，无法删除')`；delete 带 `.returning({id})`，空结果抛 `NotFoundException`）
- Controller：`@Get('categories')`、`@Post('categories')`、`@Delete('categories/:id')` 三个方法**声明在 `getCourseDetail` 之前**；写路由挂三角色 `@CanRole`（校长/招生/授课），读路由仅 `@NeedLogin`（类级已有）

### 前端
- `course.api.ts`：`fetchCategories` / `createCategory` / `deleteCategory`，沿用 `axiosForBackend` + logger 错误模式
- `CategoryManageDialog.tsx`（新建，≤300 行）：弹窗内展示类别列表（名称 + 删除图标按钮）；顶部输入框 + 「添加」按钮；删除前用 `AlertDialog` 二次确认；成功用 sonner toast 提示并刷新列表；加载态与空态处理
- `CourseListPage.tsx`：标题区「新增课程」旁加「类别管理」按钮，`CanRole` 包裹同一组角色；打开 `CategoryManageDialog`；关闭后刷新类别数据源。筛选类别下拉数据源改为「接口类别列表 ∪ 现有数据推导类别」去重排序，保证存量未管理类别仍可筛选
- `CourseFormDialog.tsx`：弹窗打开时拉取类别列表填充下拉；加载中/为空时下拉给出「暂无类别」占位提示

## 具体步骤
1. 加载 `lark-apps-db` skill，执行建表 DDL + 存量回填，确认行数
2. codegen 后重新读取 `schema.ts`
3. 更新 `shared/course.ts` 类型与常量移除
4. 实现 service + controller 类别路由，注意路由声明顺序
5. 前端 `course.api.ts` 请求方法 + `CategoryManageDialog` 组件
6. 集成列表页入口与筛选数据源、表单弹窗类别下拉动态化
7. 接口自测（增/查/删/占用阻止/重复名 409）+ 运行时日志检查后提交

## 影响范围与风险
- `GET /api/courses/categories` 必须声明在 `GET /api/courses/:id` 之前，否则被动态路由吞掉返回 404
- 已有课程表单提交逻辑不受影响（类别仍为自由 text 存储，仅下拉数据源变化）
- 存量类别回填失败不阻塞建表，但会导致筛选/表单缺项，需在自测中核对条数

## 验收标准
- `GET /api/courses/categories` 返回回填后的存量类别列表
- `POST /api/courses/categories`：正常新增返回 201；重复名返回 409；空名返回 400
- `DELETE /api/courses/categories/:id`：无课程占用时删除成功；有课程占用时返回 409 且类别保留；不存在返回 404
- 课程列表页「类别管理」弹窗可新增/删除类别，操作后筛选下拉与表单类别下拉同步更新
- 删除被占用类别时前端展示「该类别下仍有课程」提示
- 删除 `[API_TEST]` 自测类别数据
