# 需求分析
## 用户故事
1. AI 智能咨询答复：用户输入咨询问题后，系统用 AI 识别问题意图，并基于知识库内容生成答复
  - 1.1 发送问题后，会话流中展示 AI 基于知识库生成的答复（语义化组织语言，而非仅关键词命中时原文返回标准答案）
  - 1.2 换一种说法提问（如「学费是多少」问成「学下来大概要花多少钱」）也能识别并命中对应知识库条目，该条目命中次数加 1
  - 1.3 问题超出知识库范围时返回兜底答复，且该问题自动记入待补充列表
  - 1.4 答复过程展示加载状态；AI 服务异常时降级为关键词匹配，仍能保证有答复返回
2. 答复展示引用来源：命中知识库时，答复气泡附带所参考的知识库问题
  - 2.1 命中的答复下方展示「参考：知识库问题」引用信息
  - 2.2 未命中时不展示引用，仅展示兜底答复与待补充提示

## 页面列表
### 智能咨询页（既有页面增量）
1. 发送咨询问题后展示「AI 正在识别」加载态，并在会话流中渲染生成的答复
2. 命中时答复气泡下方展示参考的知识库问题引用
3. 未命中时展示兜底答复并提示已记入待补充列表，失败时展示可重试的错误提示

# 技术方案
## 开发元信息
- 开发模式: 全栈应用
- 涉及层级: [插件, 服务端, 前端]
- 说明: 数据库沿用既有 faq_knowledge_base（知识库）与 faq_miss（待补充）表，不新增表与字段；页面沿用既有智能咨询页，不新增路由

## 插件设计
| 插件名称 | 基础插件 | 用途 | 调用方式 | 关联页面 | 输入参数 | 输出类型 |
|---------|---------|------|---------|---------|---------|---------|
| FAQ 意图识别 | ai-text-to-json | 识别用户问题对应哪条启用中的知识库条目（语义匹配，含换说法识别），无匹配时返回空 | 服务端 CapabilityService（需与命中计数/未命中落库串联并统一降级） | 智能咨询页 | 用户问题 + 带编号的知识库候选列表（问题/相似问/关键词） | { matchedNo, intent } |
| 知识库答复生成 | ai-search-summary | 基于命中条目的标准答案与用户问题生成自然语言答复，严禁脱离知识库内容发挥 | 服务端 CapabilityService（结果需与命中计数同事务串联、异常时降级） | 智能咨询页 | query=用户问题，search_results=命中条目问题+标准答案 | stream\<string\>（服务端消费全文） |

链路规则说明：
- 服务端 matchFaq 流程：查询启用 FAQ → 调「FAQ 意图识别」得 matchedNo → 命中则命中次数 +1 并调「知识库答复生成」产出答复（生成失败降级返回标准答案原文）→ 未命中先回退既有关键词包含匹配兜底，仍无命中则插入 faq_miss 并返回兜底文案
- 识别插件调用异常时整体降级为既有关键词包含匹配，保证咨询可用性并记录告警日志

## 业务模型
### API 设计
#### 智能咨询页 相关
**页面路径**: /consultation
**功能全景**：
| 功能 | 实现方式 | 说明 |
|------|----------|------|
| AI 识别问题并生成知识库答复 | API + 插件 | POST /api/faqs/match 内部串联意图识别与答复生成两个插件，接口路径与请求体不变 |
| 命中次数累加 | API（既有逻辑保留） | 命中后更新 faq_knowledge_base 命中次数与更新时间 |
| 未命中问题记录 | API（既有逻辑保留） | 未命中插入 faq_miss，待补充列表可查 |
| 答复与引用渲染 | 前端 | ConsultationChatPanel 按扩展后的响应展示答复、引用与加载/错误态 |

**所需 API**:
```typescript
// 咨询提问：AI 识别意图并基于知识库生成答复 [领域模型: FaqKnowledgeBaseModel / FaqMissModel] [对应页面功能: AI 识别问题并生成知识库答复、答复与引用渲染]
POST /api/faqs/match
Request: { question: string }
Response: {
  matched: boolean;
  faqId: string | null;
  answer: string | null;          // AI 生成的答复（降级时为标准答案原文）
  matchedQuestion: string | null; // 命中的知识库问题，用于引用展示
  fallbackMessage: string | null;
}
```
