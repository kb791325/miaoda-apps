# 分页组件美化方案

## 目标与成功标准

- 修复课程列表分页文字竖排堆叠的问题（当前 `size-9` 容器过窄导致中文换行）
- 统一课程列表、学员列表的分页视觉风格，与暖橙设计系统一致
- 增加页码按钮，支持直接跳页，提升操作效率
- 分页组件 hover / 激活状态有明确视觉反馈
- 所有使用自定义 Pagination 的页面（课程列表、学员列表）效果一致

## 关键实现文件

- `client/src/components/ui/pagination.tsx` — 优化 Pagination 子组件样式与变体
- `client/src/pages/courses/CourseListPage.tsx:367-389` — 重构课程列表分页，修竖排 bug，加页码按钮
- `client/src/pages/students/StudentTable.tsx:161-193` — 同步分页风格，与课程列表一致

## 实现方案

### 1. 分页组件基础样式升级（pagination.tsx）

- `PaginationLink` 激活态改为 `bg-primary text-primary-foreground hover:bg-primary/90`，与暖橙主色一致
- `PaginationLink` 默认 ghost 态 hover 时 `bg-accent text-accent-foreground`
- 按钮圆角统一 `rounded-md`，尺寸 `size-9` 保持不变
- 增加 `PaginationPageInfo` 辅助组件（文字信息容器，`text-sm text-muted-foreground`，宽度自适应，**不设固定宽度**）

### 2. 课程列表分页重构（CourseListPage.tsx）

- 删除外层 `flex flex-col items-center gap-2 py-2` 包裹，直接用 `Pagination` 自身布局
- 分页信息文字从 `size-9` 的 span 中移出，改为独立的左侧信息区或底部信息行
- 布局改为：左侧显示「共 X 门课程 · 第 X / X 页」，中间页码按钮，右侧上一页/下一页
- 页码按钮：显示当前页附近页码（如 1 ... 4 5 6 ... 10），点击直接跳转
- 首末页禁用按钮透明度降至 40%，`cursor-not-allowed`
- 整个分页区 `py-4` 上下留白，与卡片间距协调

### 3. 学员列表分页同步（StudentTable.tsx）

- 将当前「左文字 + 右 prev/next」的布局升级为与课程列表一致的完整分页（含页码按钮）
- 底部工具栏保持 `border-t px-4 py-3`，分页组件居中或靠右
- 文字信息保留在左侧：「共 X 名学员 · 第 X / X 页」

### 4. 页码计算逻辑

- 封装页码生成逻辑：`getPageNumbers(current, total, maxVisible = 5)`
- 规则：始终显示第 1 页、最后 1 页、当前页及其前后各 1 页；超出用省略号分隔
- 总页数 ≤ 7 时全部显示，不显示省略号

## 具体步骤

1. **升级 pagination.tsx**：调整 PaginationLink 激活/hover 配色为暖橙主题，导出 PaginationPageInfo 文本组件
2. **封装页码生成 hook**：在 `client/src/utils/pagination.ts` 新增 `getPageNumbers` 工具函数
3. **重构课程列表分页**：CourseListPage 引入页码逻辑，完整分页条（左信息 + 中页码 + 右上下页），修竖排 bug
4. **同步学员列表分页**：StudentTable 同步相同分页样式
5. **验证**：课程列表页和学员列表页分页正常显示、可点击翻页、无文字竖排

## 影响范围与风险

- 仅影响前端展示，无后端改动
- 不影响数据获取逻辑和业务功能
- antd-table 内置分页（内容中心、权限页）不在本次改动范围内

## 验收标准

- 课程列表分页文字水平排列，无竖排堆叠
- 课程列表和学员列表分页均显示页码按钮，可点击跳转
- 激活页码使用琥珀橙填充，hover 有暖橙浅底反馈
- 首页/末页时对应方向按钮禁用，视觉上半透明
- 分页信息格式：「共 X 项 · 第 X / X 页」
- 响应式：窄屏时页码数量自动减少，不溢出

## 未决事项

- 内容中心 antd-table 分页是否需同步美化（默认不动，如需统一可后续定制 antd 样式）
